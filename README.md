# Library-Management-System
A full-stack desktop application built with Java (Swing, AWT, JDBC) and MySQL. Features an interactive graphical user interface, persistent relational database storage, and secure CRUD operations for managing library inventory and user records.


## Tech Stack
* Language: Java (JDK 8+)
* GUI Framework: Java Swing, AWT
* Database & Connectivity: MySQL, JDBC
* Environment: VS Code / IntelliJ IDEA, Git


## Key Features
* Graphical User Interface: Built using Java Swing components for desktop navigation and user management.
* CRUD Operations: Add, read, update, and delete records for books, members, and transactions.
* Database Integration: Utilizes JDBC with PreparedStatement interfaces to handle transactions securely and prevent SQL injection.
* State Management: Local data persistence ensuring real-time inventory updates across user actions.


## Architecture
* Object-Oriented Programming (OOP): Designed with modular class structures, encapsulation, and exception handling.
* Relational Database Schema: Configured with normalized MySQL tables linked via foreign keys to track book availability and user logs.
